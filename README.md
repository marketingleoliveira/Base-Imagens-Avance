# Base de Imagens Avance Modas

Aplicação web desenvolvida para organização, visualização e gerenciamento de ativos visuais (banco de imagens) da **Avance Modas**, facilitando a pesquisa por cor, filtros por categoria e operações de CRUD em galerias.

🌐 **Portfólio do Desenvolvedor:** [portfolioleoliveira.lovable.app](https://portfolioleoliveira.lovable.app)

---

## 📌 Sobre o Projeto

O **Base-Imagens-Avance** foi projetado para centralizar e otimizar o fluxo de mídias da marca. A plataforma permite catalogar imagens de coleções, realizar buscas avançadas por texto e variação de cor (`CategoryView`), além de oferecer suporte completo para criação, edição e exclusão de galerias (CRUD).

---

## ⚡ Tecnologias e Ferramentas

* **Frontend:** TypeScript, React, Vite, Tailwind CSS, shadcn/ui
* **Backend & Banco de Dados:** Supabase (PL/pgSQL)
* **Testes e Qualidade:** Playwright, Vitest
* **Gerenciador de Pacotes:** Bun / npm
* **Desenvolvimento Acelerado:** Lovable
